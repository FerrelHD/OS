# macOS Golden Gate Desktop Simulator

A modern, responsive, and interactive web-based macOS desktop simulator built with **React**, **Vite**, and **Tailwind CSS**.

## ✨ Features

- **Liquid Glass Desktop**: High-fidelity frosted glass aesthetics, Apple system chrome, and dynamic wallpapers.
- **Window Management Engine**: Multi-windowing, 60 FPS dragging with boundary clamping, 8-way resizing, z-index layering, and traffic lights.
- **Floating Dock**: Gaussian-curve magnification animation and running app status dots.
- **Virtual File System (VFS)**: Client-side hierarchical folder tree with `localStorage` persistence.
- **Native Apps Suite**: Finder, Safari, Google Gemini Desktop, Music, Photos, Messages, Notes, Terminal (zsh), Calculator, and System Settings.
- **System Overlays**: Spotlight Search (`Cmd+K` / `Cmd+Space`) with instant math evaluation, Control Center, and Lock Screen.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
